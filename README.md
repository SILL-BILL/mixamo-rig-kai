# Mixamo Rig Kai

Mixamo Rig Kai is a fork of the original Mixamo Rig project created by BeyondDev (Tyler Walker).

This project is currently under active development.

This fork adds:

* Variable Spine Support
* Variable Neck Support
* Optional Shoulder Support
* Reference Skeleton Mapping
* Reference Bone Generator
* Reference Template System
* Flexible Rig Generation
* Improved support for non-standard humanoid skeletons

## Reference Templates

Available Templates

* Humanoid Basic
* Humanoid Fingers
